Wat Naku Moth Nammai Punya Ram Website

A website for Wat Naku Moth Nammai Punya Ram temple — gathering temple information and publishing news and activities in one central place, with an admin management system behind it.

Backend API — Completed Frontend — In Progress
View on GitHub ← Back to Portfolio
Background

Project Overview

The temple currently has no website of its own. Information about the temple, announcements, and activities is available only on-site — visitors and interested people have no easy way to find it.

The goal of this project is to collect the temple's information and publish news and activities in a single central place: a public-facing website for visitors, plus an admin management system for the temple's staff to maintain the content.

My Work

What I Built

Everything below was built by me, hands-on, and tested with Postman.

REST API

Designed and built RESTful endpoints for every data module of the website.

CRUD Operations

Create, read, update, and delete for temple, monks, activities, news, and gallery data.

MySQL Database

Designed the schema and used parameterized queries to prevent SQL injection.

JWT Authentication

Admin login issues a JSON Web Token — protected routes verify the Bearer token.

Password Hashing

Admin passwords are hashed with bcrypt before being stored in the database.

Image Upload

Configured Multer: image files only, 5 MB limit, automatic filename renaming.

API Testing

Tested every endpoint with Postman, including login-protected routes.
