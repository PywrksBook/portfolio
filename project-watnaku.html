Project Details

Wat Nakhumothanamai Punyaram Website

Website and backend system for Wat Nakhumothanamai Punyaram, developed to centralize temple information, news, activities, and other temple-related data. The project aims to reduce scattered information and bring relevant temple information and records together into a single system for easier access and management.

Role
Full-stack Developer — Solo Project
Period
August 2026 – Present

Project Status

Backend Development — In Progress Frontend Development — Planning & Design

The project focuses on building a strong foundation in Web Development Fundamentals through a real-world project, particularly REST API development, database integration, CRUD operations, and authentication.

The backend is currently being developed, with some core API and database functionality already implemented. Additional backend systems are still being developed according to the project's requirements. For the frontend, I am currently gathering and organizing temple information and working on the initial website design and layout.

Technology Stack

HTML CSS JavaScript Node.js Express.js MySQL REST API JWT bcrypt Multer Postman Git / GitHub

Key Responsibilities

  • Gathered project requirements through interviews with temple staff to understand current information management and communication needs.
  • Analyzed the requirements and defined the project's scope, features, and data to be managed.
  • Designed and developed the backend REST API using Node.js and Express.js.
  • Implemented CRUD operations for managing temple information, monks, activities, news, and gallery data.
  • Connected the backend application with MySQL for database management.
  • Implemented administrator login and authentication using JWT and bcrypt.
  • Implemented image upload functionality using Multer.
  • Tested and verified API functionality using Postman.
  • Used Git and GitHub for source code management and version control.
